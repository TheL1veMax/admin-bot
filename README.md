# Telegram Moderation Bot 1.4

МультиБот для проверки отчетов модерации/администрации, с системой выговоров, автоматической вылачей наказаний в чате и другие полезные инструменты.

## Возможности

- Проверка отчетов модераторов и администрации
- Иерархия ролей (от модератора до главного админа)
- Система выговоров (максимум 3)
- Автоматическое удаление проверенных отчетов
- Статистика принятых/отклоненных отчетов
- Автоматическое выдача наказаний в чате
- Возможность сбрасывать принятые и сброшенные отчеты
- Возможность выдавать и снимать принятые отчеты 
- Есть специальный черный список для группы стаффа
- НОВОЕ! Система обжалований наказаний 
- И еще много других возможностей найдете в нашем боте 
## Команды

- `/start` - информация о боте и вашей роли
- `/stats` - ваша статистика отчетов
- `/vg` - выдать выговор (ответьте на сообщение пользователя)
- `/svg` - снять выговор 
- `/bl`- выдает ЧС (черный список)
- `/ubl` - убирает из ЧС
- `/sp` - сброс принятых отчетов
- `/so` - сброс отклоненных отчетов 
- `/vp` - выдать один принятый отчетов 
- `/svp` - снять один принятый отчет 
## Настройка

Отредактируйте в коде:
- `BOT_TOKEN` - токен вашего бота (Примечание: если оставить исходный код в общем доступе, токен могут добавить в различных спам рассыл, что может привести к удалению бота! Делайте переменное хранилище токена или оставляйте репозиторий приватным)
- `GROUP_CHAT_ID` - ID группы
- `MODERATOR_REPORT_TOPIC_ID` - ID темы отчетов модераторов
- `ADMIN_REPORT_TOPIC_ID` - ID темы отчетов администрации
- `WARNINGS_TOPIC_ID` - ID темы выговоров
- `USERS_ROLES` - список пользователей с ролями
и другое опционально настраивается..
